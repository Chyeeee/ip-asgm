# Datasets

This project uses two banana datasets.

## Dataset 1 - BananaImageBD

Used for banana maturity classification.

Classes:
- Green
- Semi-ripe
- Ripe
- Overripe

Download the dataset and place it inside:

data/ripeness/

## Dataset 2 - Banana Quality Dataset

Only banana images are used.

Classes:
- Class A
- Class B
- Defect

Download and place it inside:

data/quality/
